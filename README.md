# Cinemina — კინომანების აპლიკაცია (Jetpack Compose & Firebase)

ეს არის კინომოყვარულებისთვის შექმნილი Android აპლიკაცია, სადაც მომხმარებელს შეუძლია ფილმების კატალოგის დათვალიერება, ჟანრების მიხედვით ფილტრაცია, ძებნა და საკუთარი ფავორიტების სიის შექმნა. პროექტი სრულად აგებულია თანამედროვე ტექნოლოგიებით, იყენებს დეკლარატიულ UI-ს და სუფთა არქიტექტურას.

## 📌 ძირითადი ფუნქციონალი

* **ავტორიზაცია (Firebase Auth):** მომხმარებლის რეგისტრაცია (ველების ვალიდაციითა და შეცდომების ტოსტებით), სისტემაში შესვლა და სესიის შენარჩუნება (აპლიკაციის ხელახლა გახსნისას ლოგინი აღარ არის საჭირო).
* **ექაუნთის უსაფრთხო წაშლა:** პროფილის ეკრანიდან შესაძლებელია ანგარიშის სრული წაშლა. უსაფრთხოების მიზნით, პროცესი ითხოვს მომხმარებლის ხელახალ რეავტორიზაციას (Re-authentication) პაროლის შეყვანით.
* **მონაცემთა ბაზა (Cloud Firestore):** ფილმების ბაზა ინახება და იტვირთება Firestore-იდან. თითოეულ მომხმარებელს აქვს თავისი პირადი "favorites" კოლექცია.
* **რეალურ დროში სინქრონიზაცია:** ფავორიტების სია მუშაობს SnapshotListener-ზე. Home და Favorites ეკრანები მომენტალურად, რეალურ დროში რეაგირებენ ფილმის დამატებაზე ან წაშლაზე.
* **ნავიგაცია (Compose Navigation):** ეკრანებს შორის გადასვლა ხდება NavHost-ით. ქვედა ნაწილში ინტეგრირებულია BottomNavigation მენიუ (Scaffold-ის გამოყენებით).
* **Dark/Light თემები:** აპლიკაციას აქვს მორგებული ფერების პალიტრა როგორც მუქი, ისე ღია თემისთვის. ემულატორზე ან ტელეფონზე სისტემური თემის შეცვლისას, აპლიკაციის დიზაინი ავტომატურად იცვლება.

## 🏗️ არქიტექტურა და ტექნიკური მხარე

პროექტი დაწერილია MVVM პატერნით და მკაცრად მიყვება Unidirectional Data Flow (UDF) პრინციპს. თითოეული ეკრანის მდგომარეობა იმართება სუფთა სთეითებით (State) და ივენთებით (Event).

კოდის სისუფთავისა და პასუხისმგებლობების სწორად გადანაწილების მიზნით, ბიზნეს ლოგიკა ვიუმოდელებიდან სრულად არის გამოტანილი ცალკე რეპოზიტორებში:
* **RegisterRepository** — პასუხისმგებელია მხოლოდ ახალი მომხმარებლების რეგისტრაციაზე.
* **LoginRepository** — მართავს სისტემაში შესვლის (Sign In) ლოგიკას.
* **MovieRepository** — ბაზიდან იღებს ფილმებს და მართავს ფავორიტების კოლექციას.
* **ProfileRepository** — პასუხისმგებელია მიმდინარე იუზერის იმეილის წაკითხვაზე, ლოგაუთსა და ანგარიშის წაშლაზე.

ასინქრონული პროცესებისთვის და ბაზასთან მუშაობისთვის გამოყენებულია **Kotlin Coroutines** (suspend ფუნქციები და `.await()` თასკები), ხოლო რეალურ დროში მონაცემების სტრიმინგისთვის — კორუტინების **Flow / StateFlow** (`callbackFlow`-ს მეშვეობით).

## 🛠️ გამოყენებული ტექნოლოგიები:
* **Language:** Kotlin
* **UI:** Jetpack Compose (Material 3)
* **Architecture:** MVVM + Repository Pattern
* **Async & Streams:** Coroutines, Flow, StateFlow
* **Backend:** Firebase Authentication, Cloud Firestore
* **Image Loading:** Coil
